- **Styling:** Tailwind CSS (from plan.md)

## Work Steps

### 1. Initialize Vite Project
```bash
npm create vite@latest . -- --template react
```

### 2. Install Dependencies
```bash
# Core dependencies
npm install @supabase/supabase-js
npm install @tanstack/react-query
npm install react-router-dom

# Development dependencies
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
```

### 3. Configure Tailwind CSS
- Update `tailwind.config.js` to scan `.jsx` files
- Add Tailwind directives to `src/index.css`

### 4. Create Environment Variables Template
Create `.env.example`:
```
VITE_SUPABASE_URL=your_supabase_url_here
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key_here
```

### 5. Setup Project Structure
Create the following directories:
```
src/
├── components/
│   ├── auth/
│   ├── todos/
│   └── ui/
├── hooks/
├── lib/
│   └── supabase.js
├── contexts/
│   └── AuthContext.jsx
├── pages/
└── App.jsx
```

### 6. Initialize Supabase Client
Create `src/lib/supabase.js`:
```javascript
import { createClient } from '@supabase/supabase-js'

const supabaseUrl = import.meta.env.VITE_SUPABASE_URL
const supabaseAnonKey = import.meta.env.VITE_SUPABASE_ANON_KEY

export const supabase = createClient(supabaseUrl, supabaseAnonKey)
```

### 7. Setup React Query Provider
Wrap the app in `src/main.jsx` with QueryClientProvider.
