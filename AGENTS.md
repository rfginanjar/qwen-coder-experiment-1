# TodoApp — Developer Manual

## Project Context
A simple, production-ready todo application with user authentication built for rapid development and clean architecture.

**Stack:**
- React 18 + Vite (Frontend)
- Supabase (PostgreSQL + Auth + Realtime)
- Tailwind CSS (Styling)
- React Query + Context API (State)
- Vercel (Deployment)

**North Star Goals:**
- Zero backend boilerplate
- Fast iteration cycle
- Free-tier friendly
- One-click deployment

## Architecture

```
src/
├── components/         # Reusable UI components
│   ├── ui/            # Atomic UI elements (Button, Input, Card)
│   └── layout/        # Layout components (Header, Sidebar)
├── features/          # Feature-based modules
│   ├── auth/          # Login, Signup, AuthContext
│   └── todos/         # TodoList, TodoItem, TodoForm
├── hooks/             # Custom hooks (useAuth, useTodos)
├── lib/               # Supabase client, utils
├── pages/             # Route pages (Login, Dashboard)
└── App.tsx            # Root component with routing
```

**Module Responsibilities:**
- `features/auth`: Handles all authentication logic, protected routes
- `features/todos`: CRUD operations, filtering, sync with Supabase
- `lib/supabase`: Single Supabase client instance, typed queries
- `hooks`: Shared state logic across features

## Development Standards

**Naming Conventions:**
- Components: PascalCase (`TodoItem.tsx`)
- Hooks: camelCase with `use` prefix (`useTodos.ts`)
- Utils: camelCase (`formatDate.ts`)
- Files: Match component/hook name

**Code Style:**
- TypeScript strict mode enabled
- Functional components with hooks only
- ESLint + Prettier for formatting
- Tailwind classes sorted alphabetically

**Testing:**
- Vitest + React Testing Library
- Test critical user flows first
- Mock Supabase client in tests

**Commands:**
```bash
npm run dev          # Start dev server
npm run build        # Production build
npm run lint         # Run ESLint
npm run test         # Run tests
```

**Commit Style:**
```
feat: add login form
fix: resolve auth redirect loop
chore: update dependencies
docs: update README
```
